**# 📱 Meu Primeiro App — React Native

Um aplicativo simples de **contador** desenvolvido para aprender os fundamentos do **React Native** com **Expo**.

Este é o meu primeiro projeto prático na jornada de desenvolvimento mobile. O objetivo foi sair da teoria e aplicar os conceitos básicos construindo algo funcional e testável em um celular real.

---

## 🚀 Sobre o Projeto

O app exibe um número na tela e um botão. A cada toque, o número é incrementado. Parece simples, mas envolve conceitos fundamentais do React Native:

- Criação de componentes com `View`, `Text` e `TouchableOpacity`.
- Gerenciamento de estado com o hook `useState`.
- Estilização com `StyleSheet`.
- Testes em tempo real com **Expo Go** e **Fast Refresh**.
